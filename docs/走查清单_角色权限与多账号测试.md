## 一、角色体系（两套并存的角色）

| 维度 | 字段 | 取值 | 作用 |
|---|---|---|---|
| 基础组织角色 | `User.role` | `BOSS` / `MANAGER` / `LEADER` / `EMPLOYEE` / `HR` | 决定前端菜单 `admin`/`leader`/`manager_only` 可见性；后端 `is_manager`/`is_hr`/`is_boss` 判定 |
| 增长中心职能角色 | `GrowthRole.role` | `OPS`(运营) / `CLOSER`(成交师) / `FIELD`(外勤) / `VA_STAFF`(增值专员) / `VA_MANAGER`(增值主管) / `OBSERVER` | 仅作用于增长中心（线索录入/外勤/增值）的数据范围 |
| 所属部门 | `User.department.code` | `SALES`(电销部) / `OPS`(运营部) / `ACCOUNT`(会计部) / `MGMT`(管理层) | 决定合同名录按部门隔离 + 前端 `dept` 菜单 |

**前端菜单可见性规则**（`SideMenu.vue`）：
- `meta.admin` → 仅 `isAdmin`(BOSS/HR/MANAGER/超管)
- `meta.leader` → 仅 `isLeader`(BOSS/MANAGER/LEADER/超管)
- `meta.manager_only` → 仅 `isManager`(BOSS/MANAGER/超管)
- `meta.dept` → 仅本部门(电销部/会计部/运营部)或 `isBoss`/`isHR`

## 二、4 大模块 × 角色 权限矩阵

### 模块① 线索录入中心（`growth/lead-entry`）
- **菜单**：增长中心 › 线索录入中心（无任何限制）→ **所有登录用户可见**
- **数据范围** `scope_leads`：
  - 老板/管理层/超管（及 `GrowthRole.can_view_all`）→ 全量
  - 经理/主管 → 本部门（归属运营/承接人在本部门内）
  - 运营(`OPS`) → 仅自己录入的线索
  - 成交师(`CLOSER`) → 分配给自己的 + 公海待领取
  - 外勤(`FIELD`) → 不可见（空）
  - 其他 → 仅与自己相关（录入或承接）
- **录入权限**：`IsOpsOrAdmin`（运营或管理员）

### 模块② 合同订单名录（`contracts/sales` / `contracts/ops`）
- **菜单**：增长中心 › 合同订单名录 › 电销部合同 / 运营部合同（全可见）；另有「外勤与增值业务 › 合同订单」为 `manager_only`（仅 BOSS/MANAGER）
- **数据范围** `scope_contracts`：
  - 经理/老板 → 全量
  - 部门 `SALES` → 仅电销部合同
  - 部门 `OPS` → 仅运营部合同
  - 其他 → 仅自己签的单（`signer`）
- **审核/看全**：`IsContractManager`（老板或管理层）

### 模块③ 外勤与增值业务（`growth/field-tasks` / `growth/value-added`）
- **外勤任务池**（所有可见）：数据 `scope_field_tasks` → 全量(老板/经理/外勤主管) / 外勤人员看分配给自己 / 销售(创建人)看自己下单
- **增值业务部**（所有可见）：数据 `scope_projects` → 增值主管(`VA_MANAGER`+can_view_all)看全 / `VA_STAFF` 看自己 / 其他看自己(`owner`)
- **外勤精细化节点**（`FieldTaskNode`）：外勤人员 `IsFieldOrAdmin` 可更新状态+完成日期
- **合同上传**：增值业务开放上传（续费/上门拜访标记）；**外勤模块不传合同**

### 模块④ 人事组织架构（`hr/org` / `hr/entry-apply` / `hr/entry-review`）
- **组织架构** `hr/org`：`admin:true` → 仅 `isAdmin`(BOSS/HR/MANAGER/超管)
- **入职申请** `hr/entry-apply`：所有可见，员工提交
- **入职审核** `hr/entry-review`：`admin:true` → 仅 `isAdmin`；审核通过自动建账号并归入部门/岗位
- **部门制度/入职审核接口**：`IsHrManager`(BOSS/MANAGER/HR/超管)

## 四、逐模块走查步骤

### 模块① 线索录入中心
- [ ] 用 `ops01`(运营) 登录 → 进入「线索录入中心」→ 新建一条线索（填平台/账号/联系方式/归属运营人=自己/获客成本/签单金额）→ 保存
- [ ] 同一账号进入「数据看板」→ 确认自己录入的线索出现、转化率/占比有值
- [ ] 切换 `closer01`(成交师) 登录 → 在线索工作台/公海：应**看不到** ops01 录入但未被分配的线索（除非进入公海）
- [ ] 点击某条线索的「穿透」→ 应只看到该归属运营人名下的平台/账号线索与转化统计
- [ ] `admin` 登录 → 列表应能看到全公司所有线索

### 模块② 合同订单名录
- [ ] 用 `sales_mgr`(电销部 MANAGER) 进入「电销部合同」→ 新建一条（企业名称/税号/服务内容/金额/收款账户/附件）
- [ ] 切换 `ops01`(运营部) 进入「运营部合同」→ 列表**不应出现** sales_mgr 建的电销部合同（部门隔离）
- [ ] `ops01` 在「运营部合同」新建一条 → 自己可见、`sales_mgr` 在电销部视角不可见
- [ ] 附件上传：选收款截图/合同扫描件/PDF → 确认能上传并能打开下载链接

### 模块③ 外勤与增值业务
- [ ] `admin`/`sales_mgr` 进入「外勤任务池」→ 新建外勤任务（客户类型/精细化节点：资料确认→执照→刻章→银行→税务）
- [ ] 切换 `field01`(外勤) → 应只看到派给自己的任务；进入节点进度 → 把某节点状态改为「进行中/已完成」并填完成日期 → 保存
- [ ] `sales_mgr`(创建人) 应能在自己下单的任务里看到外勤进度（无需询问）
- [ ] 进入「增值业务部」→ `va01` 新建项目（标记续费/上门拜访）→ 上传合同附件
- [ ] 切换 `vamgr01`(增值主管) → 应看到 va01 建的所有项目（全量）；`va01` 只看到自己的

### 模块④ 人事组织架构
- [ ] `hr01`(HR) 登录 → 左侧应出现「组织架构」「入职审核」菜单（普通员工看不到）
- [ ] 进入「组织架构」→ 查看钉钉式部门树 + 岗位/制度；新建部门/子部门/制度并保存
- [ ] `ops01`(普通员工) 登录 → 确认**没有**「组织架构」「入职审核」菜单
- [ ] `ops01` 进入「入职申请」提交一条 → `hr01` 在「入职审核」通过 → 系统应自动建账号并归入对应部门/岗位

## 五、边界与注意
- 同能级员工互相不可见对方单据（如成交师 A 看不到成交师 B 的分配单，只能看公海）。
- 外勤模块**不上传合同**；合同上传只在「增值业务部」与「合同订单名录」开放。
- `GrowthRole.can_view_all` 是个体授权开关，仅对个别账号开放全量，不默认给 HR。
- 当前线上为 SQLite 预览，重启沙箱数据清空；正式交付建议切 PostgreSQL（见部署手册）。
