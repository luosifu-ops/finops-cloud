# 钉钉通讯录同步 · 配置指南（保姆级）

> 功能位置：网站 → 行政人事部 → **钉钉同步**
> 作用：把钉钉里的部门和员工一键拉进系统，老员工按手机号自动匹配，不动角色和密码。
> 本集成只「拉取」不「推送」，不会往钉钉写任何数据。

## 一、在钉钉后台创建应用（约 5 分钟）

1. 电脑浏览器打开 **https://open-dev.dingtalk.com/** ，用管理员钉钉扫码登录
2. 顶部「应用开发」→「**创建应用**」→ 选「**H5微应用**」
   - 应用名称随意，如「财税企管云」
   - 应用描述随意
3. 创建后进入应用 → 左侧「**凭证与基础信息**」，记下：
   - **AppKey**（类似 `dingXXXXXXXXXXXXXXXX`）
   - **AppSecret**（点查看，复制）
   - **AgentId**（同页可见）

## 二、开通通讯录权限

1. 应用左侧「**权限管理**」→ 搜索「通讯录」
2. 开通以下两个权限：
   - **通讯录部门信息读权限**（qyapi_base 相关）
   - **通讯录部门成员读权限**
3. 如需把员工手机号同步进来（用于匹配老员工账号），再开通：
   - **个人信息读权限**（手机号字段）
4. 左侧「**版本管理与发布**」→ 发布应用（企业内部应用，发布后权限才生效）

## 三、把凭证交给服务器

把这三行发给管理员（或自己 SSH 到服务器执行）：

```bash
ssh ubuntu@140.143.85.54
sudo sed -i 's|^DINGTALK_APP_KEY=.*|DINGTALK_APP_KEY=你的AppKey|; s|^DINGTALK_APP_SECRET=.*|DINGTALK_APP_SECRET=你的Secret|; s|^DINGTALK_AGENT_ID=.*|DINGTALK_AGENT_ID=你的AgentId|' /opt/finops-cloud/deploy/prod/.env
cd /opt/finops-cloud && sudo docker compose -f deploy/prod/docker-compose.yml --env-file deploy/prod/.env up -d --build web
```

## 四、执行同步

1. 网站登录 → 行政人事部 → **钉钉同步**
2. 状态显示「已配置」→ 先点 **「预演（不写入数据）」** 看数量对不对
3. 确认无误 → **「一键同步通讯录」**

## 同步规则（重要）

| 项目 | 规则 |
|---|---|
| 部门 | 按钉钉部门树全量同步，编码 = `DT+钉钉部门ID`（不占用 SALES/ACCOUNT/OPS/MGMT 四个业务码） |
| 老员工 | **手机号匹配**则只补部门，不改角色/密码/状态 |
| 新员工 | 自动建号（手机号即账号），**默认不可登录**——需管理员在「员工档案」重置密码后启用 |
| 钉钉职务 | 自动同步为系统「岗位」（同名复用） |
