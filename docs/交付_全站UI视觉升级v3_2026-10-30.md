## 一、设计方向

| 维度 | 决策 | 理由 |
|---|---|---|
| 风格方向 | Corporate-Stable × Refined Luxury（企业稳重 × 轻奢质感） | 财税 To B 产品，客户为中小企业老板与会计，需要「可信、稳重、贵」而非「潮流、张扬」 |
| 主色 | `#2a4fd4` 皇室靛蓝（原 `#2f6bff`） | 降低饱和度、加深明度，摆脱通用互联网蓝的「模板感」 |
| 点缀色 | `#c8a44d` 香槟金 | 仅用于 5 处：品牌徽标光点、页头分隔短线、卡片标题竖条末端、侧栏激活竖条、AI 浮球外环 |
| 中性色 | 带微暖偏移的墨色阶 | 通用冷灰是后台系统廉价感的首要来源 |
| 阴影 | 三层极低透明度叠加 | 替代单层硬投影，建立真实光照与空间层次 |
| 圆角 | 卡片 14px / 控件 10px | 收敛原 16px，更克制 |

**核心手法**：改一处令牌，全站 120+ 页面联动。所有颜色、间距、圆角均可追溯到 `:root` 变量。

## 三、顺带修复的 2 处既有缺陷（需知悉）

### 3.1 整页白屏（严重）

- **现象**：访问 `/onboarding/exam`（在线考试）等页面时**整页空白**，控制台报 `Cannot read properties of undefined (reading 'title')`
- **根因**：`router/index.js` 第 139 行 `{ path: 'sales/data-wall', redirect: '/system/data-wall' }` 是纯重定向路由，**没有 `meta` 字段**。`SideMenu.vue` 的 `allRoutes` 过滤条件为 `!r.meta?.hidden`，`r.meta` 为 `undefined` 时该表达式返回 `true`，于是这条无 meta 的路由进入了菜单树；渲染 `e.item.meta.title` 时抛出 TypeError，Vue 渲染中断，整个布局挂掉
- **修复**：`SideMenu.vue` 过滤条件改为 `.filter(r => r.meta && !r.meta.hidden)`
- **影响面**：仅影响菜单渲染，路由跳转与页面功能不受影响

### 3.2 套餐页显示 `约省 NaN%`

- **现象**：免费版套餐显示「年付 ¥0.00（约省 NaN%）」
- **根因**：`price_monthly` 为字符串 `"0.00"`（truthy），`price_yearly / (price_monthly * 12)` 得到 `0/0 = NaN`
- **修复**：`yearSave()` 增加 `Number()` 转换与零值防护；模板对零价格显示「永久免费 · 不限时长」

## 五、回滚方式

**源码备份**：

```
web/src/.ui-backup-20261030/          # 5 个核心文件 .bak
/tmp/finops-src-backup-20261030.tgz   # 完整 src 打包（274KB）
```

**生产产物备份**：

```
/tmp/spa_index_backup_<时间戳>.html   # 构建前的旧入口文件
```

**回滚步骤**：

```bash
# 方式一：只回滚入口（若仅新包有问题）
cp /tmp/spa_index_backup_*.html backend/spa/index.html

# 方式二：完整回滚源码后重新构建
cd web && tar -xzf /tmp/finops-src-backup-20261030.tgz
npm run build
```

## 六、上线须知

1. **本次仅在本地生成了生产包**，线上服务器（`/opt/finops-cloud`）**尚未更新**。上线需另行同步 `backend/spa` 到服务器并重启 Gunicorn/uWSGI。

3. `web/src` 当前有 40+ 个文件处于未提交状态（包含本次改动与此前工作），建议验收通过后统一 `git commit`。
4. 建议上线前在服务器侧再次执行一次「登录 → 仪表盘 → 列表页 → 导出 PDF」四步走查，重点确认 PDF 导出正常（本次已移除页面动画规避该风险）。
