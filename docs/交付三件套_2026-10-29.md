## 三、部署说明

### 服务器环境
- 阿里云轻量 Ubuntu 140.143.85.54（成都），SSH 免密：`ssh ubuntu@140.143.85.54`
- Docker Compose 位于 `/opt/finops-cloud/deploy/prod/`（prod-web-1 / prod-db-1 / prod-caddy-1，Caddy 自动 HTTPS）
- 代码 build 进镜像（Dockerfile COPY backend），entrypoint 启动时自动 `migrate` + `collectstatic` + gunicorn :8000

### 标准发布流程
```bash
# 1. 本地构建前端（产物输出到 backend/spa/）
cd finops-cloud/web && npm run build

# 2. 备份线上后端
ssh ubuntu@140.143.85.54 "sudo -n cp -a /opt/finops-cloud/backend /opt/finops-cloud/backend.bak-\$(date +%m%d%H%M)"

# 3. 同步代码（先到 /tmp 再原子替换，排除缓存）
rsync -a --delete --exclude '__pycache__' --exclude '*.pyc' backend/ \
  ubuntu@140.143.85.54:/tmp/finops-backend-new/
ssh ubuntu@140.143.85.54 "sudo -n rsync -a --delete /tmp/finops-backend-new/ /opt/finops-cloud/backend/"

# 4. 重建容器（自动跑迁移）
ssh ubuntu@140.143.85.54 "cd /opt/finops-cloud/deploy/prod && sudo -n docker compose up -d --build web"

# 5. 验证
ssh ubuntu@140.143.85.54 "sudo -n docker logs prod-web-1 --tail 10"
```

### 回滚

