# 财税企管云 · 小程序对标与功能补齐报告

> 生成时间：2026-09-25｜对标对象：财税代账类 / 企业 OA 类 / 销售 CRM 类主流小程序
> 数据源：联网检索（买购网十大代账软件榜、云帐房/慧算账官网、钉钉 vs 企业微信 OA 评测、纷享销客/销售易 CRM 白皮书，2026）

## 一、市面同款核心能力拆解

### 1. 财税代账类（云帐房 / 慧算账 / 用友易代账 / 金蝶账无忧）
- 智能取票、批量记账报税、客户账套管理
- **机构管理**：客户 / 任务 / 续费分派（代账公司刚需）
- 经营分析看板（收入趋势、成本构成、利润、现金流预警）
- 风险监控、月底待办提醒、小规模 500W 预警

### 2. 企业 OA 类（钉钉 / 企业微信 / 飞书）
- **考勤打卡**：多班次、定位/WiFi/蓝牙、外勤打卡、自动关联请假加班
- **OA 审批**：请假 / 报销 / 出差 / 加班，自定义表单 + 流程引擎（申请→审批→反馈→归档闭环）
- **公告通知**：强制触达、已读回执
- 薪酬绩效、入职离职全流程

### 3. 销售 CRM 类（纷享销客 / 销售易）
- 线索统一管理、客户 360° 画像、商机 / 销售漏斗
- 外勤拜访、合同回款、BI 数据看板
- AI 赋能：智能跟单、赢单预测、流失预警

## 三、对标后补齐的高价值缺失项（本轮已交付）
1. **请假发起闭环**：原仅有列表，已加表单（8 类假别、日期、天数、事由），POST 实测通过。
2. **报销发起闭环**：原后端有接口小程序无入口，已加表单（6 类费用、金额、发票号、事由）。
3. **公告通知**：OA 标配，已加列表+点击标记已读+未读数。
4. **我的线索（CRM）**：对标 CRM「线索统一管理」，已加列表（运营/成交师/转化率/拨打）。

## 四、仍缺失项与建议（按优先级）
| 优先级 | 功能 | 说明 | 落地成本 |
|---|---|---|---|
| P1 | 经营数据看板 | 对标云帐房经营分析，接 /api/dashboard/ 做老板驾驶舱移动版 | 中 |
| P1 | OA 审批发起（加班/出差/采购/用印） | 后端接口齐全，复用请假表单范式批量补 | 低 |
| P2 | 请假/报销进度推送 | 接微信订阅消息，对标企微强提醒 | 中（需小程序认证） |
| P2 | 客户 360° 画像详情页 | 线索点进去看跟进记录/商机 | 低 |
| P3 | AI 赋能 | 智能跟单建议、流失预警（需模型接入） | 高 |
| P3 | 电子签/发票 OCR | 对标慧算账 AI 识票 | 高 |

## 五、结论
小程序与网站功能对齐度已从「严重不同步」提升到「核心场景基本对齐」；对标市面三类同款后，最关键的「发起闭环（请假/报销）+ 公告 + 线索 CRM」已补齐。下一步建议优先做 **经营数据看板** 与 **其余 OA 审批发起**，即可在移动端覆盖代账公司日常 90% 作业。
