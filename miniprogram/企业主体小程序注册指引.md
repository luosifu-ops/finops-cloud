## 二、注册步骤（约 15 分钟，法人配合 1 次扫脸）

1. **准备邮箱**：确认拟用邮箱能收信、且没绑过任何微信平台账号。
2. **进注册页**：浏览器打开 `mp.weixin.qq.com` → 右上角「立即注册」→ 选「**小程序**」。
3. **填邮箱**：输入新邮箱 → 获取验证码 → 设置密码（记进密码本）→ 提交。
4. **邮箱激活**：登录该邮箱，点微信发来的激活链接。
5. **选主体类型**：回到注册页继续 → 主体类型选「**企业**」。
6. **填企业信息**：
   - 企业名称：云南财税通集团有限公司
   - 营业执照注册号：91530103MABP04430B
   - 注册方式二选一：
     - **推荐：法人代表微信验证**（快，当天完成）→ 让果元明用本人微信扫码 + 人脸识别
     - 对公账户打款（慢，要等打款 1-2 天，且需财务配合查小金额到账）
7. **填管理员信息**：填你自己的姓名、身份证号、手机号；用你本人微信扫码确认绑定管理员。
8. **提交完成** → 用邮箱+密码登录 `mp.weixin.qq.com`（小程序后台）。
9. **取 AppID**：后台左侧「**开发 → 开发管理 → 开发设置**」→ 复制 **AppID（wx 开头 18 位）**。
10. **顺手填小程序名称**：「设置 → 基本设置 → 名称」，建议先试「**云财税通**」（规避已注册的「财税通」商标）；被占用就换「云财税通企管云」等。
11. **把 AppID 发给智囊** → 我改 `project.config.json`（只动 appid 字段）→ 你重跑导入+开窗命令 → 继续编译预览。

## 三、常见卡点

| 卡点 | 解法 |
|---|---|
| 邮箱提示已被占用 | 换一个全新邮箱（该邮箱注册过任意微信平台都会占） |

| 法人扫脸失败 | 确认果元明微信已实名、本人操作、光线充足；失败 3 次改走对公打款 |
| 名称被占用 | 备选：云财税通 / 云财税通企管云 / 财税企管云 |

## 四、拿到 AppID 之后（一条命令搞定）

> 代码侧已体检通过：42 个页面全部存在、sitemap.json 存在、纯原生**无 npm 依赖（不用构建 npm）**、urlCheck=False（本地不校验域名）。拿到 AppID 后基本能一次编译过。

Boss 在 Mac 终端跑**这一条**（把 AppID 换成你刚拿到的）：

```bash
bash ~/mp_use_appid.sh <你的AppID>
```

脚本会自动：① 只改 `project.config.json` 的 appid 字段 ② `project_import` 导入 ③ `open_project_window` 开窗 → 你点『编译』即可。

## 五、两个容易忽略的提醒

1. **开发者工具登录的微信 ≠ 小程序管理员**：之前扫码登录开发者工具用的是 Boss 的微信。若注册时把该小程序管理员设成别人（或法人），需在「小程序后台 → 成员管理」把**登录开发者工具那台微信**加为「开发者」或「体验者」，否则导入会报权限错。最省事：注册时管理员就填你自己（扫码登录开发者工具的）微信。
2. **法人扫脸验证只一次**：注册「注册方式」选「法人代表微信验证」时，让果元明微信扫脸即可，几分钟搞定；若选对公打款要等 1-2 天。
