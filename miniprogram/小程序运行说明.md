# 财税企管云 · 微信小程序（鲜艳亮丽版）

> 与「财税企管云」管理网站同一套 Django 后端 API，原生小程序（无第三方框架），配色鲜艳、卡片化、移动端体验完整。

## 一、项目位置
```
finops-cloud/miniprogram/
```
- `app.js`：全局请求层（自动带 token，兼容「信封 {code,data}」与「裸 DRF 分页 {results,count}」两类返回）
- `app.wxss`：鲜艳主题（粉/橙/蓝/绿/紫渐变 + 彩色统计卡/按钮/九宫格）
- `app.json`：17 个页面 + 4 个 tabBar（驾驶舱/工作台/汇报/我的）

## 二、如何运行（本地预览）
1. 用**微信开发者工具**打开 → 导入项目 → 目录选 `finops-cloud/miniprogram`。
2. AppID 选「测试号」即可（当前 `project.config.json` 已设 `touristappid`）。
3. 右上角「详情 → 本地设置」勾选 **不校验合法域名、web-view（真机调试也需勾）**。
4. 后端须在本机运行：`python manage.py runserver 127.0.0.1:8000`（小程序 `BASE_URL` 默认指向它）。
5. 登录页已预填演示账号：`boss / admin123`，点「登录」即可进入。

## 三、功能清单（17 页，全部对接真实接口）
| 模块 | 页面 | 能力 |
|---|---|---|
| 驾驶舱 | index | 业绩总览、各部门进度、8 宫格入口 |
| 工作台 | workbench | 考勤打卡/签退、待我审批、我的入职任务 |
| 汇报 | report | 日报/周报/月报「写汇报 + 我的历史」 |
| 我的 | mine | 个人信息、全部功能入口、待审数、退出登录 |
| 入职培训 | onboarding/index | 学习路径 + 必修完成率 |
| 资料 | onboarding/list + detail | 企业文化/制度/财税知识阅读、制度确认、标记已学 |
| 考试 | onboarding/exam + examDetail | 开始考试 → 答题 → 自动判分 |
| 任务 | onboarding/task | 我的入职任务清单 + 标记完成 |
| 入职资料 | onboarding/detail?type=profile | 查看/提交入职资料 |
| 电销 | sales/list + detail | 线索列表（按状态筛选）、线索详情、写通话记录 |
| 会计 | accounting/index + task | 月度做账任务统计+列表，点任务进详情看税额/收入，并可「完成节点」推进做账流（收票→做账→申报） |
| 运营 | ops/index + stats | 平台/计划/累计投放费与线索；「投放明细」按平台筛选每日数据（花费/线索/ROI） |
| 审批 | approval/list + detail + create | 待我审批/我发起的、同意/驳回；右下角「＋」发起请假/加班/出差/报销，自动生成审批单进入审批流 |

## 五、顺带修复的后端 Bug（影响网站+小程序）
`apps/sales/serializers.py` 的 `CallRecordSerializer` 把 `user` 设为必填，但 `perform_create`
本应自动归属当前用户 → 任何「新建通话记录」都 400。已加 `extra_kwargs={"user":{"required":False}}`，
现由后端自动归属当前登录人。（网站电销「写通话」同样受益。）

## 六、生产上线注意事项
1. `app.js` 的 `BASE_URL` 改为 `https://你的域名/api`，并在**小程序后台 → 开发管理 → 服务器域名**
   配置 request 合法域名（必须 https + ICP 备案）。
2. 微信登录：当前为账号密码登录演示。真实微信扫码/授权登录需在小程序后台配置自己的
   **AppID + AppSecret**，并在后端 `accounts` 实现 `code→openid` 换取（已有 `wx-login` 接口骨架）。
3. 媒体/附件（身份证、合同等图片）走后端 media 地址，需在小程序后台配 uploadFile/downloadFile 域名。
4. tabBar 图标当前用 emoji，生产可替换为 png 图标（放在 `pages/.../icon` 或 `images/`）。
